# Ensino Médio e Técnico

Repositório criado para armazenar exercícios, atividades e pequenos projetos desenvolvidos durante o **2º ano do Ensino Médio Técnico em Desenvolvimento de Sistemas (DS)**.

Os arquivos foram desenvolvidos com o objetivo de praticar lógica de programação, resolução de problemas, estruturas de dados, funções e Programação Orientada a Objetos, além de explorar a criação de aplicações simples utilizando Python.

## Conteúdos praticados

Durante o desenvolvimento dos exercícios e projetos, foram trabalhados conceitos como:

- Variáveis e tipos de dados
- Entrada e saída de dados
- Operadores matemáticos e lógicos
- Estruturas condicionais (`if`, `elif`, `else`)
- Estruturas de repetição (`for` e `while`)
- Funções e modularização
- Listas e dicionários
- Manipulação e processamento de dados
- Geração de números aleatórios
- Tratamento básico de exceções
- Programação Orientada a Objetos (POO)
- Classes, atributos e métodos
- Estruturas de menu e interação com o usuário
- Simulação de sistemas através do terminal

## Exemplos de exercícios e projetos

### Jogos e simulações

- `Jogo.py` — jogo de adivinhação com número aleatório e limite de tentativas.
- `casino.py` — simulação de um jogo baseado em sorte.
- `score.py` — exercício envolvendo pontuação.
- `urna.py` — simulação de votação.
- `par ou ímpar.py` — exercício de lógica com números pares e ímpares.

### Exercícios de lógica e matemática

- `Fibonacci.py` — implementação da sequência de Fibonacci.
- `tabuada.py` — cálculo e exibição da tabuada.
- `vetor.py` — processamento de dados numéricos.
- `Media s11.py` — exercício envolvendo cálculo de média.
- `Salario por hora.py` — cálculo de salário com base nas horas trabalhadas.
- `temperatura.py` — conversão e manipulação de temperaturas.
- `aposentadoria.py` — exercício envolvendo critérios de aposentadoria.
- `positivo ou ímpar.py` — prática de estruturas condicionais.

### Pequenos sistemas e aplicações

- `Katchau.py` — simulação de uma loja de produtos de informática, com categorias, carrinho de compras e finalização de pedidos.
- `menu.py` — sistema de cadastro e consulta de equipes.
- `TabelaCurso.LSS12.py` — aplicação para seleção de cursos por área e nível de dificuldade.
- `saque.py` — simulação de operações de saque.
- `relatorio.py` — geração de informações em formato de relatório.
- `eletronicos.py` — exercício envolvendo produtos eletrônicos.
- `IOT.py` — simulação de comandos para dispositivos.

### Fundamentos de programação

- `poo1.py` — introdução à Programação Orientada a Objetos utilizando uma classe `Lampada`.
- `poo2.py` — exercício de POO utilizando uma classe `Usuario`, com atributos e métodos.
- `dicionário.py` — manipulação de dicionários.
- `lista tutorial.py` — exercícios práticos com listas.
- `item.py` — exercício envolvendo manipulação de itens.
- `teste.py` — testes e experimentos realizados durante os estudos.

## Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/ensino-medio-ds.git
```

### 2. Acesse a pasta do projeto

```bash
cd ensino-medio-ds
```

### 3. Execute um arquivo Python

Por exemplo:

```bash
python Jogo.py
```

Ou:

```bash
python Katchau.py
```

Os arquivos podem ser executados individualmente. Alguns programas exigem interação pelo terminal.
